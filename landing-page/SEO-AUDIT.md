# OpenReview SEO audit — 2026-10-21

Scope: landing-page source and generated static HTML. The public domain could not be reached through the audit web tool. No Search Console, production crawl, traffic, or Core Web Vitals data was available. Changes are local and require deployment.

## Positioning

Primary: OpenReview, an open-source AI code review agent.
Supporting topics: bring your own API keys (BYOK), self-hosted code review, custom Markdown review rules.
Keep these concepts in useful visible copy rather than repeating keywords. Preserve the brand headline and explain the product directly below it.

## Findings and changes

| Area | Before | After |
| --- | --- | --- |
| Rendering | Static Astro HTML | Retained; content is available without JavaScript |
| Home title | Brand and slogan | OpenReview — Open-Source Code Review Agent |
| Description and hero | Generic review platform/teamwork copy | Agent, API keys, review rules, self-hosting |
| About and journal | Broad editorial descriptions | More specific code review and open-source context |
| Canonicals | Present, using Astro site URL | Retained; query parameters excluded |
| Sitemap | Generated by Astro | Retained |
| robots.txt | Missing (not itself a crawl block) | Allow crawling; reference generated sitemap using configured site URL |
| Social metadata | OG text only, small Twitter card | Shared 1200×630 PNG, image alt text, large Twitter card, site name |
| Structured data | Missing | WebSite, Organization, WebPage; homepage SoftwareSourceCode; BlogPosting and dates on posts |
| Headings | One H1 per page | Retained |
| Hero image transfer | Multi-megabyte PNGs originally | Previously switched to 141–182 KB WebP files |

No ratings, prices, unverified licensing, or customer claims were added. Structured data describes existing page content; it does not guarantee rich results or rankings.

## Validation

- Production build and Astro diagnostics pass.
- All eight generated HTML pages contain one H1, a description, a canonical URL, and parseable JSON-LD; titles are unique.
- Generated robots.txt points to https://openreview.si/sitemap-index.xml with the default configuration.
- Social preview image rendered and visually inspected.

## Remaining production work

1. Confirm https://openreview.si is the intended production origin. Set SITE_URL during the build if different; canonical URLs, social images, robots sitemap URL, and schema depend on it.
2. Deploy, verify a Search Console domain property, submit /sitemap-index.xml, and inspect the homepage URL. Indexing and rankings are not verified in this audit.
3. Confirm HTTP redirects consistently resolve to the canonical HTTPS host, all public routes respond successfully, and the host does not inject noindex or restrictive X-Robots-Tag headers.
4. Run Rich Results Test and Search Console URL Inspection on deployed pages. SoftwareSourceCode is descriptive schema, not a promise of a Google software-app rich result.
5. Measure mobile Core Web Vitals and Lighthouse after deployment. No performance score or speed increase was measured here.
6. Add substantive setup documentation for API keys, self-hosting, and Markdown review rules as product details stabilize. Link it from the relevant cards; avoid thin keyword-only pages.
7. Track searches such as “open source code review agent”, “self hosted AI code review”, and “code review bring your own API key” in Search Console; keyword volumes and competitiveness were not researched.
